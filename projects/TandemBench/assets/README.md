# TandemBench website assets

These files were assembled from the final submission set used to build the project page.

## Documents
- `paper.pdf` — current WACV main manuscript.
- `supplement.pdf` — supplementary PDF included in the release archive.
- `tandembench_release.zip` — current reproducibility release archive.

## Images extracted from the PDFs
- `teaser.png` — Figure 1 overview from the main paper.
- `additivity_panel.png` — results panel from Figure 1.
- `perturbation_schedule.png` — Figure 2 perturbation schedule from the main paper.
- `corruption_suite.png` — qualitative corruption suite from Supplement Figure S1.
- `fire_rates.png` — fire-rate plot from Supplement Figure S2.

The image assets are crops of rendered submission PDFs so the website matches the submitted figures exactly.
